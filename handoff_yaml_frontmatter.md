---

Write a detailed handoff summary to `HANDOFF.md` covering: (1) key decisions made, (2) files changed and why, (3) current blockers or open questions, (4) important context to preserve, and (5) what's done vs. what remains. Be thorough enough that a fresh Claude instance can continue seamlessly.

You have blanket permission to edit HANDOFF.md when this command is issued, even if the current session requires confirmation before editing other files.
